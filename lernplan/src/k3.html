Was ist eine Zufallsvariable? Das theoretische Gegenstück zum Merkmal
V05 · Folie 5–8
Eine Zufallsvariable \(X\) ordnet jedem Ergebnis eines Zufallsexperiments eine Zahl zu. Statt Häufigkeiten hat sie Wahrscheinlichkeiten.
Deskriptive Statistik (Tag 1)Wahrscheinlichkeitsrechnung (heute)

MerkmalsausprägungenTräger \(T\) = mögliche Werte

Beispiel: Zwei Würfel werden geworfen. \(\Omega\) hat 36 Paare. \(X\) = Augensumme ordnet z. B. dem Paar \((2, 5)\) die Zahl 7 zu. \(X\) ist diskret (Träger \(\{2, \dots, 12\}\)). Eine Wartezeit ist dagegen stetig.

2
Wahrscheinlichkeitsfunktion und Verteilungsfunktion Die zwei Beschreibungen einer diskreten ZV
Testat 4 · A1
\(P(X = x_i) = p_i\) mit \(p_i \ge 0\) und \(\sum p_i = 1\). Die Verteilungsfunktion \(F(x) = P(X \le x)\) ist eine Treppe — genau wie \(\hat F\) an Tag 1.
✓ Beispiel (Tutorium 6) · \(P(X = x) = \dfrac{x}{c}\) für \(x \in \{1, 2, 3, 4\}\), sonst 0

Konstante bestimmen: Alle Wahrscheinlichkeiten müssen zusammen 1 ergeben:

\[ \frac 1c + \frac 2c + \frac 3c + \frac 4c = \frac{10}{c} \overset{!}{=} 1 \quad\Rightarrow\quad c = 10 \]
Wahrscheinlichkeitsfunktion — Stäbe, keine Flächen.
Verteilungsfunktion — Treppe, Sprung = \(p_i\).
\[ F(x) = \begin{cases} 0 & x \lt 1 \\ 0.1 & 1 \le x \lt 2 \\ 0.3 & 2 \le x \lt 3 \\ 0.6 & 3 \le x \lt 4 \\ 1 & x \ge 4 \end{cases} \]
● Wahrscheinlichkeiten ablesen — diskret!
\(P(X \le b) = F(b)\)\(P(X \le 2) = 0.3\)
\(P(X \lt b) = F(\text{nächstkleinerer Wert})\)\(P(X \lt 3) = P(X \le 2) = 0.3\)
\(P(X \gt a) = 1 - F(a)\)\(P(X \gt 2) = 1 - 0.3 = 0.7\)
\(P(X \ge a) = 1 - F(\text{nächstkleinerer Wert})\)\(P(X \ge 2) = 1 - P(X \le 1) = 0.9\)
\(P(a \lt X \le b) = F(b) - F(a)\)\(P(1 \lt X \le 3) = 0.6 - 0.1 = 0.5\)
TR · Kesikli değişkende < ve ≤ farkı

Kesikli (sayma) değişkende \(P(X \lt 4)\) ile \(P(X \le 4)\) farklıdır — aradaki fark tam \(P(X = 4)\). Kural: her şeyi "\(\le\)" biçimine çevir. \(X \lt 4\) → \(X \le 3\). \(X \ge 2\) → \(1 - P(X \le 1)\). Tutorium bunu "häufiger Fehler" diye işaretliyor.

Erwartungswert und Varianz (diskret) Wie Mittelwert und Varianz — mit Wahrscheinlichkeiten als Gewichten
V06 · Folie 4–20
\(E(X) = \sum x\,P(X = x)\). \(\mathrm{Var}(X) = E(X^2) - (E(X))^2\) mit \(E(X^2) = \sum x^2 P(X = x)\).
● Formeln
\[ E(X) = \sum_x x \cdot P(X = x) \qquad E(g(X)) = \sum_x g(x)\, P(X = x) \qquad \mathrm{Var}(X) = E(X^2) - \big(E(X)\big)^2 \]

Gesetz der großen Zahlen: Wiederholt man das Experiment sehr oft, nähert sich der Mittelwert der Ergebnisse \(E(X)\).

✓ Beispiel · Würfelspiel (Tutorium 5)

Einsatz 3 €, Auszahlung = Augenzahl. Gewinn \(G = \text{Augenzahl} - 3\), Träger \(\{-2, -1, 0, 1, 2, 3\}\), jeweils \(\frac 16\).

\(E(G) = \dfrac{-2 - 1 + 0 + 1 + 2 + 3}{6} = 0.5\) · \(E(G^2) = \dfrac{4 + 1 + 0 + 1 + 4 + 9}{6} = \dfrac{19}{6}\) · \(\mathrm{Var}(G) = \dfrac{19}{6} - 0.25 = 2.9167\)

4
Rechenregeln für \(E\) und Var Die Werkzeuge für A7 und für alle Tests
A7 · 5 P
Konstanten ziehst du aus \(E\) einfach heraus, aus Var quadriert. Summen darf man bei \(E\) immer, bei Var nur bei Unabhängigkeit zerlegen.
● Die Regeln
\(E(aX + b) = a\,E(X) + b\)\(\mathrm{Var}(aX + b) = a^2\,\mathrm{Var}(X)\) · \(\mathrm{sd}(aX + b) = |a|\,\mathrm{sd}(X)\)
\(E(X + Y) = E(X) + E(Y)\) — immer\(\mathrm{Var}(X + Y) = \mathrm{Var}(X) + \mathrm{Var}(Y)\) — nur unabhängig
\(E(X \cdot Y) = E(X)\,E(Y)\) — nur unabhängigallgemein: \(\mathrm{Var}(X + Y) = \mathrm{Var}X + \mathrm{Var}Y + 2\,\mathrm{Cov}(X, Y)\)
\(E(c) = c\) für eine Konstante\(\mathrm{Var}(c) = 0\)
✓ Beispiel (Tutorium 6) · \(Z = 0.5X + Y\), unabhängig, \(E(Z) = 8.5\), \(\mathrm{Var}(Y) = 1\)

\(E(Z) = 0.5 \cdot 3 + E(Y) = 8.5\) → \(E(Y) = 7\) · \(\mathrm{Var}(Z) = 0.5^2 \cdot 1 + 1 = 1.25\)

TR · A7 tipi soru için taktik

İfadeyi toplamlara ayır, her terimde sabitleri dışarı çek, bilinen \(E(X_i)\)'yi yerine koy. \(E\left(\frac 14\right) = \frac 14\) (sabit). Çarpım/bölümde dikkat: \(E\left(\dfrac{1}{X}\right) \ne \dfrac{1}{E(X)}\) genelde. Tag 4'te A7'yi tam çözeceğiz.

5
Die Dichte Wahrscheinlichkeit = Fläche
Testat 4 · A4–A5
Bei stetigen ZV hat jeder einzelne Wert Wahrscheinlichkeit 0. Wahrscheinlichkeiten sind Flächen unter der Dichte \(f\): \(P(a \le X \le b) = \int_a^b f(x)\,dx\).
● Eine gültige Dichte braucht genau zwei Dinge (Testat 4, A4)
  • \(f(x) \ge 0\) für alle \(x\)
  • \(\int_{-\infty}^{\infty} f(x)\,dx = 1\)

Nicht nötig: \(f(x) \le 1\) (Werte über 1 sind erlaubt!), Stetigkeit oder Monotonie. Und \(P(X = x) = 0 \ne f(x)\). Deshalb ist bei stetigen ZV \(P(X \lt b) = P(X \le b)\).

✓ Beispiel (Testat 4) · \(f(x) = c\,(x - 2)\) für \(2 \le x \le 3\), sonst 0
\[ \int_2^3 c\,(x - 2)\,dx = c\left[\frac{x^2}{2} - 2x\right]_2^3 = c\,\big((4.5 - 6) - (2 - 4)\big) = c \cdot 0.5 \overset{!}{=} 1 \;\Rightarrow\; c = 2 \]

Und \(c = 2 \gt 0\), also ist \(f \ge 0\) auf \([2, 3]\) ✓. Beachte: \(f(3) = 2 \gt 1\) — trotzdem gültig.

6
Verteilungsfunktion und Quantile (stetig) Einmal integrieren, danach nur noch einsetzen
Tutorium 6 · A2
\(F(x) = \int_{-\infty}^x f(t)\,dt\). Danach: \(P(a \lt X \le b) = F(b) - F(a)\). Ein Quantil \(q_\alpha\) löst \(F(q_\alpha) = \alpha\).
✓ Beispiel (Tutorium 6) · \(f(x) = \frac 12 (x - 4)\) für \(4 \le x \le 6\)

Verteilungsfunktion (Integrationsvariable \(t\), obere Grenze \(x\)):

\[ F(x) = \int_4^x \frac 12 (t - 4)\,dt = \left[\frac{t^2}{4} - 2t\right]_4^x = \frac{x^2}{4} - 2x + 4 \qquad (4 \le x \le 6) \] \[ F(x) = \begin{cases} 0 & x \lt 4 \\ \frac 14 x^2 - 2x + 4 & 4 \le x \le 6 \\ 1 & x \gt 6 \end{cases} \]
  • \(P(X \gt 5.2) = 1 - F(5.2) = 1 - (6.76 - 10.4 + 4) = 1 - 0.36 = 0.64\)
  • \(P(X \lt 5.1) = F(5.1) = 6.5025 - 10.2 + 4 = 0.3025\)
  • \(P(4.5 \lt X \lt 5.5) = F(5.5) - F(4.5) = 0.5625 - 0.0625 = 0.5\)
  • Median: \(\frac 14 q^2 - 2q + 4 = 0.5\) → \(q^2 - 8q + 14 = 0\) → \(q = 4 + \sqrt 2 = 5.4142\) (die andere Lösung \(4 - \sqrt 2\) liegt nicht in \([4, 6]\))
▲ Drei Punkteverluste bei \(F(x)\)
  • Nur den mittleren Teil angeben — die Fälle \(x \lt 4\) (\(F = 0\)) und \(x \gt 6\) (\(F = 1\)) gehören dazu.
  • Die untere Grenze vergessen: \(\left[\dfrac{t^2}{4} - 2t\right]_4^x\) liefert das \(+4\).
  • Probe vergessen: \(F(6)\) muss 1 sein: \(9 - 12 + 4 = 1\) ✓

Erwartungswert und Varianz (stetig) Summe wird Integral
V06 · Folie 4–20
\(E(X) = \int x f(x)\,dx\), \(E(X^2) = \int x^2 f(x)\,dx\), \(\mathrm{Var}(X) = E(X^2) - (E(X))^2\). Symmetrische Dichte um \(a\) → \(E(X) = a\).
✓ Weiter mit \(f(x) = \frac 12 (x - 4)\)
\[ E(X) = \int_4^6 x \cdot \tfrac 12 (x - 4)\,dx = \left[\frac{x^3}{6} - x^2\right]_4^6 = (36 - 36) - \left(\frac{64}{6} - 16\right) = \frac{16}{3} = 5.3333 \] \[ E(X^2) = \int_4^6 x^2 \cdot \tfrac 12 (x - 4)\,dx = \left[\frac{x^4}{8} - \frac{2x^3}{3}\right]_4^6 = 18 - (-10.6667) = 28.6667 \]

→ \(\mathrm{Var}(X) = 28.6667 - 5.3333^2 = 28.6667 - 28.4444 = 0.2222\)

Bernoulli und Binomial Zählen von Erfolgen
A3 (c) · Testat 4 · A2
\(X \sim B(n, \pi)\): \(P(X = x) = \binom nx \pi^x (1-\pi)^{n-x}\). Voraussetzung: \(n\) unabhängige Versuche mit gleicher Erfolgswahrscheinlichkeit \(\pi\).
● Formeln
\[ P(X = x) = \binom{n}{x}\,\pi^x\,(1 - \pi)^{n - x}, \quad x = 0, 1, \dots, n \qquad \binom nx = \frac{n!}{x!\,(n - x)!} \]

\(X = X_1 + \dots + X_n\) mit \(X_i \sim Be(\pi)\) unabhängig → \(E(X) = n\pi\), \(\mathrm{Var}(X) = n\pi(1 - \pi)\).

✓ Beispiel (Tutorium 7) · Würfelsumme durch 4 teilbar

Zwei Würfel: Summen 4, 8, 12 → 3 + 5 + 1 = 9 von 36 Paaren → \(\pi = 0.25\). 10 Würfe: \(Y \sim B(10, 0.25)\), \(E(Y) = 2.5\), \(\mathrm{Var}(Y) = 1.875\).

  • \(P(Y = 1) = \binom{10}{1} 0.25^1\, 0.75^9 = 10 \cdot 0.25 \cdot 0.0751 = 0.188\)
  • \(P(Y = 2) = \binom{10}{2} 0.25^2\, 0.75^8 = 45 \cdot 0.0625 \cdot 0.1001 = 0.282\)
  • \(P(Y \le 2) = 0.0563 + 0.1877 + 0.2816 = 0.526\)
9
Poisson Zählen ohne Obergrenze — wichtig für Teil B
B (f)(g) · 15 P
\(X \sim Po(\lambda)\): \(P(X = x) = \dfrac{\lambda^x}{x!} e^{-\lambda}\), \(x = 0, 1, 2, \dots\) Besonderheit: \(E(X) = \mathrm{Var}(X) = \lambda\).
✓ Beispiel (Tutorium 7) · Tore pro Spiel, \(X \sim Po(2)\)
  • \(P(X = 3) = \dfrac{2^3}{3!}e^{-2} = \frac 86 \cdot 0.1353 = 0.180\)
  • \(P(X \ge 2) = 1 - P(X = 0) - P(X = 1) = 1 - e^{-2}(1 + 2) = 1 - 0.4060 = 0.594\)
  • \(Z = 2X + 4\): \(E(Z) = 8\), \(\mathrm{Var}(Z) = 4 \cdot 2 = 8\). \(V = 2X + 1\): \(E(V) = 5 \ne \mathrm{Var}(V) = 8\) → \(V\) ist nicht poissonverteilt.
▲ Probeklausur Teil B (f)

„Nehmen Sie an, \(X \sim Po(\lambda)\) mit \(\lambda = 20\) … individuelle Likelihoods“ — das ist einfach \(P(X = x_i)\) für jede Beobachtung, in R dpois(x, 20). Das Produkt aller Werte ist die Likelihood (Tag 4).

Gleichverteilung, Exponentialverteilung, Weibull Die stetigen Modelle ohne Tabelle
A6 · Testat 4 · A8
Exponential: \(F(x) = 1 - e^{-\lambda x}\), also \(P(X \gt x) = e^{-\lambda x}\) und \(E(X) = 1/\lambda\). Aus „im Mittel 3 Stunden“ folgt \(\lambda = 1/3\).
● Gleichverteilung \(U(a, b)\)
\[ f(x) = \frac{1}{b - a}, \; a \le x \le b \] \[ F(x) = \frac{x - a}{b - a} \]

\(E = \dfrac{a + b}{2}\) · \(\mathrm{Var} = \dfrac{(b - a)^2}{12}\)

● Exponential \(Exp(\lambda)\)
\[ f(x) = \lambda e^{-\lambda x}, \; x \ge 0 \] \[ F(x) = 1 - e^{-\lambda x} \]

\(E = \frac 1\lambda\) · \(\mathrm{Var} = \dfrac{1}{\lambda^2}\)

✓ Beispiel (Tutorium 7) · Zeit zwischen zwei Gewittern, im Mittel 3 Monate

\(E(Y) = 3 = \frac 1\lambda\) → \(\lambda = \frac 13\), \(\mathrm{Var}(Y) = 9\). \(P(Y \gt 4) = e^{-4/3} = 0.2636\).

Testat 4: Fuchs jagt im Mittel 3 Stunden → \(P(X \gt 10) = e^{-10/3} = 0.0357\).

● Weibull-Verteilung (Probeklausur A6)
\[ f(x; \lambda, r) = r\lambda(\lambda x)^{r-1}\exp\big(-(\lambda x)^r\big) \qquad F(x) = 1 - \exp\big(-(\lambda x)^r\big) \]

Mit \(r = 1\): \(f(x) = \lambda e^{-\lambda x}\) — das ist genau die Exponentialverteilung. Genau das nutzt A6: „Nehmen Sie an, dass \(r = 1\).“

▲ Dichtewerte addieren ist falsch (Tutorium 7, A3 h)

sum(dexp(1:6, 1/3)) = 0.729 ist keine Wahrscheinlichkeit. Richtig: \(P(1 \lt Y \lt 6) = F(6) - F(1)\) = pexp(6, 1/3) - pexp(1, 1/3) = 0.581.

Normalverteilung und Standardisieren Jede Normalverteilung mit einer einzigen Tabelle
A8 · Testat 4 · A9
\(X \sim N(\mu, \sigma^2)\) → \(Z = \dfrac{X - \mu}{\sigma} \sim N(0, 1)\) → \(P(X \le x) = \Phi\!\left(\dfrac{x - \mu}{\sigma}\right)\). Negative \(z\): \(\Phi(-z) = 1 - \Phi(z)\).
● Das Rezept
  1. \(\mu\) und \(\sigma\) aufschreiben — Achtung: \(N(500, 9)\) heißt \(\sigma^2 = 9\), also \(\sigma = 3\).
  2. Standardisieren: \(z = \dfrac{x - \mu}{\sigma}\), auf zwei Nachkommastellen runden (Tabelle).
  3. \(\Phi(z)\) in der Tabelle ablesen (Anhang). Für \(z \lt 0\): \(\Phi(z) = 1 - \Phi(-z)\).
  4. \(P(X \gt x) = 1 - \Phi(z)\) · \(P(a \lt X \lt b) = \Phi(z_b) - \Phi(z_a)\)

Quantile rückwärts: \(q_\alpha = \mu + \sigma z_\alpha\) mit \(z_{0.9} = 1.28\), \(z_{0.95} = 1.64\), \(z_{0.975} = 1.96\), \(z_{0.99} = 2.33\) (Vorlesungstabelle). Symmetrie: \(z_\alpha = -z_{1-\alpha}\).

✓ Vorlesungsbeispiel · Flugzeit \(X \sim N(183, 14^2)\)

\(P(180 \lt X \lt 190) = \Phi\left(\dfrac{190 - 183}{14}\right) - \Phi\left(\dfrac{180 - 183}{14}\right) = \Phi(0.5) - \Phi(-0.21) = 0.6915 - (1 - 0.5832) = 0.2747\)

✓ Beispiel (Testat 4) · Mehlpackungen \(X \sim N(500, 9)\), also \(\sigma = 3\)
  • \(P(X \gt 500) = 1 - \Phi(0) = 0.5\) (Symmetrie)
  • \(P(X \ge 505) = 1 - \Phi\left(\dfrac{5}{3}\right) = 1 - \Phi(1.67) = 1 - 0.9525 = 0.0475\)
  • \(P(496 \le X \le 502) = \Phi(0.67) - \Phi(-1.33) = 0.7486 - (1 - 0.9082) = 0.6568\)
● Transformationen und Summen

\(Y = aX + b\) → \(Y \sim N(a\mu + b,\; a^2\sigma^2)\) · \(X, Y\) unabhängig normal → \(X + Y \sim N(\mu_X + \mu_Y,\; \sigma_X^2 + \sigma_Y^2)\).

Beispiel: 10 Packungen à \(N(500, 16)\) unabhängig → Summe \(S \sim N(5000, 160)\), \(\sigma_S = \sqrt{160} = 12.6491\) — nicht \(10 \cdot 4\)!

Zentraler Grenzwertsatz und uiv Warum die Normalverteilung überall auftaucht
A8 · Testat 4 · A7
Sind \(X_1, \dots, X_n\) unabhängig und identisch verteilt (uiv/iid) mit \(E = \mu\) und Var \(= \sigma^2\), dann ist \(\bar X\) für großes \(n\) ungefähr \(N\!\left(\mu, \dfrac{\sigma^2}{n}\right)\) — egal welche Verteilung die \(X_i\) haben.
● Die zwei Formen
\[ \bar X \overset{a}{\sim} N\!\left(\mu,\; \frac{\sigma^2}{n}\right) \qquad\qquad \sqrt{n}\,\frac{\bar X - \mu}{\sigma} \overset{a}{\sim} N(0, 1) \]

Die zweite Form ist genau die Prüfgröße des Gauß-Tests in A8: \(Z = \dfrac{\bar X - \mu_0}{\sigma}\sqrt n\). Ohne ZGWS gilt schon exakt: \(E(\bar X) = \mu\), \(\mathrm{Var}(\bar X) = \dfrac{\sigma^2}{n}\) (Rechenregeln aus Schritt 4).

✓ Beispiel · \(n = 100\), \(\mu = 4\), \(\sigma^2 = 3\)

\(\bar X \overset{a}{\sim} N(4,\, 0.03)\), \(\mathrm{sd}(\bar X) = \sqrt{0.03} = 0.1732\). \(P(\bar X \lt 4.3) = \Phi\left(\dfrac{0.3}{0.1732}\right) = \Phi(1.73) = 0.9582\). Und \(P(\bar X \lt 4) = \Phi(0) = 0.5\) (Testat 4).
