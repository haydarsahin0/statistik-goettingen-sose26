A4-Vorlage · Klausurteil A · Block Tag 1 – Das darfst du mitnehmen: 1 A4-Blatt, beidseitig, handgeschrieben, selbst angefertigt (Kopien werden auf dem Deckblatt vermerkt). Dieser Block ist für die obere Hälfte der Vorderseite geplant; der Rest bleibt für Tag 2–4. Klein und sauber abschreiben – beim Abschreiben lernst du.
Form Ende 3 NK (oder gekürzter Bruch), Zwischen ≥ 4 NK · Dezimalpunkt · 1 Lösung/Kästchen · „nicht lösbar“ + Begründung.
Skala · Maße nominal: Modus · ordinal: + Median, Quantile · kardinal: + \(\bar x\), \(s^2\), r. 1–7-Skala = ordinal. 0/1 = ordinal/binär: mod, med, \(\bar x\)=Anteil, \(s^2=\bar x(1-\bar x)\) od. „nicht sinnvoll“. Anzahl → diskret; Zeit/Gewicht/Geld → stetig.
Stichprobe einfach zufällig · geschichtet (aus jeder Gruppe) · Klumpen (ganze Gruppen, alle befragen) · Quote (bewusst). Störvariable → Randomisierung.
Häufigkeiten \(f=h/n,\ H_j=\sum_{i\le j}h_i,\ F=H/n,\ h_j=H_j-H_{j-1}\). ≤k: F(k) · <k: F(k−1) · >k: 1−F(k) · ≥k: 1−F(k−1).
Histogramm Klassen \((c_{j-1},c_j]\) (Vorlesung). Höhe \(=f_j/\text{Breite}=h_j/(\text{Breite}\cdot n)\); Fläche = Anteil; Σ = 1. Teilintervall: Σ Breite·Höhe; Anzahl ×n. „Annahme: gleichverteilt in der Klasse“. Modalklasse = größtes \(h_j\) (nicht höchste Säule!).
ECDF \(\hat F\) 0 für x<a₁; \(F_1\) für a₁≤x<a₂; …; 1 für x≥a_max. Skizze: ● links ○ rechts, nicht senkrecht verbinden, Linien ins Unendliche, Achsen beschriften.
Lage Median sortiert! n unger.: \(x_{((n+1)/2)}\); ger.: \(\frac12(x_{(n/2)}+x_{(n/2+1)})\). Tabelle: \(\bar x=\sum a_jf_j\). Klassiert: \(\bar x_K=\sum f_jm_j,\ s_K^2=\sum f_jm_j^2-\bar x_K^2\). Gruppen: \(\frac{n_1\bar x_1+n_2\bar x_2}{n_1+n_2}\). Fehlender Wert: Summe \(=n\bar x\). rechtsschief: \(\bar x>x_{med}>x_{mod}\).
Quantil \(n\alpha\) = Platz! nicht ganz → aufrunden; ganz k → \(\frac12(x_{(k)}+x_{(k+1)})\). IQR \(=x_{.75}-x_{.25}\).
Streuung \(s^2=\frac{\sum x^2}{n}-\bar x^2\) (empir., \(\tilde s^2\)) · \(s_*^2=\frac{n}{n-1}s^2\) (keine Wurzel!) · \(s=\sqrt{s^2}\). R var/sd = \(s_*\). TR: σx = s, sx = \(s_*\). \(y=a+bx\): \(\bar y=a+b\bar x\), \(s_y^2=b^2s_x^2\), \(s_y,\text{IQR}_y\) ×|b|.
Boxplot Zäune \(x_{.25}-1.5\,\text{IQR}\), \(x_{.75}+1.5\,\text{IQR}\). Außerhalb = Punkt. Whisker bis zum letzten echten Wert innerhalb. Box = \(x_{.25}\)…\(x_{.75}\).
Kontingenztafel · χ² „A unter B“ = h(A∩B)/h(B); „aller / und“ → /n. Bedingte Anteile verschieden → Zusammenhang. \(\tilde h=\frac{\text{Zeile}\cdot\text{Spalte}}{n}\), \(\chi^2=\sum\frac{(h-\tilde h)^2}{\tilde h}\) ≥ 0; 0 ⇔ unabh.
Kov · Korr \(s_{xy}=\frac{\sum xy}{n}-\bar x\bar y\) · \(r=\frac{s_{xy}}{\sqrt{s_x^2s_y^2}}\) · \(s_{xy}=r s_xs_y\). |r|: <.3 schwach, <.7 mittel, ≥.7 stark. Satz: Stärke + Richtung + linear + Merkmale. Tafel: \(\overline{xy}=\sum a_jb_kf_{jk}\). \(u=a+bx,v=c+dy\): \(s_{uv}=bd\,s_{xy}\); r gleich (bd<0: −r).
Spearman Ränge (Bindung = Ø-Rang), dann Pearson mit Rängen; \(1-\frac{6\sum d^2}{n(n^2-1)}\). Ränge gleich → 1, umgekehrt → −1. Satz: „monoton“.
Kausalität (2 P) Nein, nur Zusammenhang · Drittvariable (+ Bsp.) / umgekehrte Richtung · Kausal nur mit randomisiertem Experiment. r=0 bei Parabel möglich; unkorreliert ⇏ unabhängig.
